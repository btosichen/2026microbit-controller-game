# 用 Google 試算表記錄遊戲成績｜GAS 設定說明

每局遊戲結束時，`index.html` 會把成績上傳到 Google 試算表。試算表會自動整理出「排行榜」和「玩家統計」，遊戲裡也能看到全班的雲端排行榜。

## 一、會記錄哪些資料

「遊戲紀錄」工作表中，每一局遊戲是一列：

| 欄 | 內容 | 說明 |
|---|---|---|
| A | 紀錄編號 | 每局唯一，用來避免重複記錄 |
| B | 上傳時間 | 伺服器收到資料的時間（台北時間） |
| C | 玩家暱稱 | 最多 12 字 |
| D | 分數 | |
| E | 擊落數 | |
| F | 到達波次 | |
| G | 擊敗頭目 | |
| H | 難度 | 簡單／普通／困難 |
| I | 遊戲時長(秒) | 不含暫停的時間 |
| J、K | 開始時間、結束時間 | |
| L | 結束原因 | 被敵彈擊中、撞機、撞上雪山、燃料耗盡… |
| M | 操控方式 | 鍵盤或 micro:bit |
| N | 特殊攻擊次數 | |
| O | 撿到道具數 | |
| P | 瀏覽器 | 例如 Chrome / Windows |
| Q | 遊戲版本 | |
| R | 備註 | 分數或擊落數異常偏高時，會自動提醒老師檢查 |

另外兩個工作表會自動更新：
- **排行榜**：依分數排出前 20 名。
- **玩家統計**：每位玩家的遊玩次數、最高分、平均分數、總擊落數、最高波次和總遊玩時間。

## 二、建立試算表與 GAS（約 5 分鐘，只需要做一次）

1. 到 Google 雲端硬碟，建立一個新的 **Google 試算表**，例如命名為「藍鷹出擊成績」。
2. 在試算表上方點選 **擴充功能 → Apps Script**。
3. 刪除編輯器裡原本的內容，把 `Code.gs` 的全部內容貼上，然後按 **儲存**（磁碟片圖示）。
4. 在上方的函式選單選 **setup**，按 **執行**。
   - 第一次執行時會要求授權：按「審查權限」，選擇你的 Google 帳號。如果出現「Google 尚未驗證這個應用程式」，點「進階」→「前往（不安全）」→「允許」。這是你自己寫的程式，可以放心授權。
   - 執行完成後，回到試算表，會看到「遊戲紀錄」「排行榜」「玩家統計」三個工作表。
5. （可選）在函式選單選 **testInsert** 並按執行。「遊戲紀錄」中出現一筆「測試飛行員」，就表示寫入功能正常。測試完可以刪除這一列。

## 三、部署成網頁應用程式

1. 在 Apps Script 右上角點 **部署 → 新增部署作業**。
2. 點左邊的齒輪，選 **網頁應用程式**。
3. 設定：
   - 說明：例如「藍鷹出擊 v1」
   - **執行身分：我**
   - **誰可以存取：所有人**（學生不需要登入 Google 就能上傳成績）
4. 按 **部署**，然後複製「網頁應用程式網址」。網址會以 `https://script.google.com/macros/s/` 開頭、`/exec` 結尾。

> 學校網域帳號（Google Workspace for Education）如果看不到「所有人」選項，表示學校管理員有限制。這時可以選「（學校名稱）內的所有使用者」，但學生必須在同一個瀏覽器先登入學校帳號；否則請改用個人 Gmail 帳號建立。

## 四、把網址填進遊戲

方法 A（推薦，不用改程式）：
1. 開啟遊戲，點右上角的「**排行榜．設定**」。
2. 在「雲端紀錄（Google 試算表）」欄位貼上網址，按「**儲存**」，再按「**測試連線**」。
3. 看到「✔ 連線成功：『藍鷹出擊成績』目前有 N 筆紀錄」就完成了。

方法 A 的網址只存在那一台電腦的瀏覽器裡。如果有很多台電腦，建議改用方法 B。

方法 B（一次設定，所有電腦都生效）：用記事本開啟 `index.html`，找到下面這一行：
```js
cloud: { url: '', token: 'skyace-2026', ...
```
把網址貼在 `url: ''` 的兩個單引號中間，然後存檔。

## 五、確認有記錄成功

1. 玩一局，生命歸零後，結算畫面會顯示「✔ 已記錄到 Google 試算表」。
2. 打開試算表的「遊戲紀錄」，可以看到新的一列。「排行榜」和「玩家統計」也會自動更新。
3. 在遊戲的「排行榜．設定」面板按「重新整理」，可以看到全班的雲端排行榜，自己的成績會用黃色標示。

**網路斷線時**：結算畫面會顯示「⚠ 上傳失敗，成績已暫存在這台電腦」。下次打開遊戲、下一局結束，或按「重送暫存」時，會自動補送，而且不會重複記錄。

## 六、修改與注意事項

- **修改 GAS 程式後**，必須重新部署才會生效：點「部署 → 管理部署作業 → 鉛筆圖示 → 版本選『新版本』→ 部署」。這樣網址不會改變。如果改用「新增部署作業」，會產生新網址，遊戲裡的網址也要跟著換。
- **上傳密碼 TOKEN**：`Code.gs` 開頭的 `TOKEN` 要和 `index.html` 裡 `CONFIG.cloud.token` 的值相同。建議每個班級或學期改成自己的密碼。注意：這只能擋掉隨便亂送的資料。懂程式的人仍然可以從網頁原始碼看到密碼，所以「備註」欄會標出可疑的高分，方便人工檢查。
- **隱私**：請學生使用暱稱或座號，不要輸入真實全名或其他個人資料。
- **清除測試資料**：直接在「遊戲紀錄」刪除那幾列即可，排行榜和統計會自動重新計算。
- **使用限制**：Google 免費帳號的 Apps Script 每天可以處理數萬次請求，一般班級使用綽綽有餘。
- **連線問題**：
  - 「TOKEN 不正確」：兩邊的 TOKEN 不一樣。
  - 「回傳的不是 JSON」：部署時「誰可以存取」沒有選「所有人」，或網址貼錯（必須以 `/exec` 結尾）。
  - 「無法連線」：請檢查電腦網路，或學校防火牆是否擋了 script.google.com。
